# Sgommando — kit brand (v1)

Stato: bozza da approvare da Tony. Nessun account esiste ancora.

| File | Uso |
|---|---|
| `scheda-brand.png` | Scheda con palette, font, avatar, logo e motto |
| `logo-orizzontale-scuro/chiaro .svg/.png` | Logo orizzontale (PNG trasparente, 2400 px) |
| `logo-impilato-scuro/chiaro .svg/.png` | Versione impilata |
| `avatar.png` / `avatar.svg` | Foto profilo 1080x1080, dentro il ritaglio circolare |
| `brand-tokens.json` | Colori, font e misure leggibili da script |
| `build.py` | Rigenera tutto (`python3 build.py`; servono `fonttools` e `cairosvg`; usa `../../_shared/tools/`) |

## Palette
- `#1B1D21` (Grigio asfalto)
- `#FF6B1A` (Arancio segnale)
- `#FFFFFF` (Bianco)
- `#38BDF8` (Azzurro quadro)

## Font
- Titoli: **Barlow Condensed**, maiuscolo (Google Fonts, OFL).
- Testo e caption: **Inter** Regular e Bold (Google Fonts, OFL).

## Motto
"Più fumo che arrosto"

## Regole d'uso
Non deformare il logo, non cambiare i colori, niente marchi o foto di terzi. Negli SVG il testo è convertito in tracciati.
