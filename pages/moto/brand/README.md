# Col Ginocchio a terra — kit brand (v1)

Stato: bozza da approvare da Tony. Nessun account esiste ancora.

| File | Uso |
|---|---|
| `scheda-brand.png` | Scheda con palette, font, avatar, logo e motto |
| `logo-orizzontale-scuro/chiaro .svg/.png` | Logo orizzontale (PNG trasparente, 2400 px) |
| `logo-impilato-scuro/chiaro .svg/.png` | Versione impilata |

## Regole d'uso
Non deformare il logo, non cambiare i colori, niente marchi o foto di terzi. Negli SVG il testo è convertito in tracciati.
